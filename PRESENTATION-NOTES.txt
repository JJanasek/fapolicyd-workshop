Audience: SELinux / policy people. Focus = configure trust, rules.d, conf;

Glossary
--------
trust DB      known files (path + size + hash); rpmdb + filedb
rules.d       first-match allow/deny policy fragments
compiled.rules  assembled policy — never edit by hand
FANOTIFY      fapolicyd denial (ausearch -m FANOTIFY)
AVC           SELinux denial (ausearch -m AVC)
pattern=ld_so special subject: dynamic-linker smuggle path


================================================================================
WHY (short — they already know MAC)
================================================================================

Beside SELinux, not instead:
  SELinux = behavior (labels). fapolicyd = known artifact? (trust).
  One Permission denied → AVC, FANOTIFY, or both.

Gain: block unpackaged home/tmp/opt; stop ld.so smuggle; trust ≠ bin_t.
Limits: root can disable it; not a MAC substitute.


================================================================================
WHAT YOU CONFIGURE
================================================================================

Three places: Trust DB · rules.d/ · fapolicyd.conf

Path: open/exec → fanotify → fapolicyd (trust + rules) → allow/deny
Hard rule: never strace/gdb/ptrace the daemon (SIGSTOP → deadlock).

Trust: rpmdb (RPM + plugin) + filedb (you, trust.d/).
Rules: decision  permission  subject : object   (first match)

Shipped pattern=ld_so:
  deny_audit perm=any pattern=ld_so : all
  = linker-smuggle subject → deny any object + audit.
  Trusted ld.so does NOT bless untrusted ELF.

Integrity: none → size (pragmatic) → sha256 (expensive).


================================================================================
CONFIGURE
================================================================================

A — Install
  dnf install fapolicyd fapolicyd-selinux rpm-plugin-fapolicyd
  ≥1 audit rule (else deny_audit quiet): auditctl -w /etc/shadow -p w
  systemctl enable --now fapolicyd
  fapolicyd-cli --check-status / --list

B — Trust /opt (default remediation)
  --file add /opt/myapp --trust-file myapp && --update
  Prefer trust trees over allow-rule sprawl.

C — rules.d (who/how, not just “known”)
  Number above catch-all deny. fagenrules → --check-rules --lint → reload.
  Bad candidate → previous ruleset kept.

D — Conf: permissive=1 soak → fix → 0; integrity=size before sha256

Denied?
  1) ausearch -m AVC
  2) ausearch -m FANOTIFY -i
     Compact FANOTIFY often has NO path (-f may miss).
     Path + rule:N → --debug-deny
  3) unclear → stop; fapolicyd --permissive --debug-deny; reproduce

Dual stack: one binary can hit BOTH.
  Wrong label → AVC; untrusted → FANOTIFY. Fix each layer.

FANOTIFY deny: known software? → trust. Who/how? → rules.d.

Anti-patterns: allow sprawl; edit compiled.rules; SELinux allow ⇒ fapolicyd allow.
