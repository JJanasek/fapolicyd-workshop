fapolicyd Power Users — slide notes (English)
================================================================================
Use with presentation.pdf. Same titles as the slides. Then do EXERCISES.md.

Audience: SELinux / policy people. Focus = configure trust, rules.d, conf;
triage FANOTIFY vs AVC. Not an intro to MAC.

Glossary
--------
trust DB      known files (path + size + hash); rpmdb + filedb
rules.d       first-match allow/deny policy fragments
compiled.rules  assembled policy — never edit by hand
FANOTIFY      fapolicyd denial (ausearch -m FANOTIFY)
AVC           SELinux denial (ausearch -m AVC)
pattern=ld_so special subject: dynamic-linker smuggle path


================================================================================
WHY (short — they already know MAC)
================================================================================

Beside SELinux, not instead:
  SELinux = behavior (labels). fapolicyd = known artifact? (trust).
  One Permission denied → AVC, FANOTIFY, or both.

Gain: block unpackaged home/tmp/opt; stop ld.so smuggle; trust ≠ bin_t.
Limits: root can disable it; not a MAC substitute.


================================================================================
WHAT YOU CONFIGURE
================================================================================

Four places:
  1) Trust DB
  2) rules.d/
  3) fapolicyd.conf
  4) fapolicyd-filter.conf — which RPM paths enter trust (man 5)

Path: open/exec → fanotify → fapolicyd (trust + rules) → allow/deny
Hard rule: never strace/gdb/ptrace the daemon (SIGSTOP → deadlock).

Trust: rpmdb (inside fapolicyd) + filedb (trust.d/).
Filter: fapolicyd-filter.conf (+ include / - exclude). Applied at RPM
import, not per decision. fapolicyd-cli --test-filter PATH. Not drilled.

Rules: decision  permission  subject : object   (first match)
known-libs: 42-trusted-elf allows trusted ELF execute for everyone.
A later 55- ping deny never matches. Put exceptions BEFORE 42 (e.g. 39-).
Shell scripts: shipped allow ftype=text/x-shellscript — use an ELF for deny labs.

Shipped pattern=ld_so:
  deny_audit perm=any pattern=ld_so : all
  = linker-smuggle subject → deny any object + audit.
  Trusted ld.so does NOT bless untrusted ELF.

Integrity: none | size | ima | sha256. Try size before sha256.


================================================================================
CONFIGURE
================================================================================

A — Install
  dnf install fapolicyd
  (rawhide: rpm-plugin-fapolicyd obsolete, folded into fapolicyd)
  ≥1 audit rule (else deny_audit quiet):
    auditctl -a always,exit -F path=/etc/shadow -F perm=wa
  systemctl enable --now fapolicyd
  fapolicyd-cli --check-status / --list

B — Trust /opt (default remediation)
  --file add /opt/myapp --trust-file myapp && --update
  Prefer trust trees over allow-rule sprawl.

C — rules.d (who/how, not just “known”)
  Number BEFORE allow perm=execute all : trust=1 (42-trusted-elf).
  Example: rules.d/39-ping.rules, gid=fapo_workshop (not wheel — fapo is in wheel).
  One physical line per rule (fagenrules does not join continuations).
  Apply: fagenrules --load   (NOT systemctl reload — no ExecReload).
  Or: fagenrules && fapolicyd-cli --reload-rules
  Then --check-rules --lint → --list | nl (ping lines above 42).
  Failed in-daemon reload keeps previous ruleset.
  Run the test as fapo. Root hits uid=0 trust=1 first.

D — Conf: permissive=1 soak → fix → 0; integrity none|size|ima|sha256

Denied?
  1) ausearch -m AVC
  2) ausearch -m FANOTIFY -i
     Compact FANOTIFY often has NO path (-f may miss).
     Path + rule:N → --debug-deny
  3) unclear → stop; fapolicyd --permissive --debug-deny; reproduce

Dual stack: one binary can hit BOTH.
  Wrong label → AVC; untrusted → FANOTIFY. Fix each layer.
  Use type tmp_t. user_tmp_t is executable by staff_t while
  staff_exec_content is on (default) — FANOTIFY only.
  restorecon on /var/tmp often does nothing (file_contexts <<none>>).

FANOTIFY deny: known software? → trust. Who/how? → rules.d.

Anti-patterns: allow sprawl; edit compiled.rules; SELinux allow ⇒ fapolicyd allow.
